# Excuse Agent

A deterministic, standard-library-only MakeFun entry that writes one funny AI-agent excuse to `output/entry.txt`.

## Run

```bash
python3 main.py
```

The program creates `output/` when needed and writes the same excuse every time. The entry is under 200 characters.
